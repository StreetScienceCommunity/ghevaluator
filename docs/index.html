Welcome to Galaxy History Evaluator’s documentation!¶

A command-line tool to evaluate Galaxy histories, e.g. of participants of a training, by comparing them to a reference: the workflow of a tutorial, or a reference history such as the tutor’s own run of the tutorial.

For each history, it tells which steps are done, missing, run on other inputs or with other settings, which results were copied from another history, and gives a score. The results are HTML, Markdown and JSON reports, and an overview when several histories are evaluated. Nothing is created or changed in Galaxy.
